## Shape Factory

Shape Factory is a simple interactive web application that allows users to generate colorful geometric shapes directly in the browser. Users can choose between different shapes and colors, then dynamically create them on the page using JavaScript.

This project demonstrates the use of object-oriented programming concepts in JavaScript, DOM manipulation, event handling, and dynamic UI updates.

## Features
- Create squares and circles dynamically
- Choose different colors for each shape
- Object-oriented design using a Shape class
- Clickable generated shapes with console output information
- Maximum shape limit to prevent overcrowding

## Tech Stack
- HTML – Structure and layout
- CSS3 – Styling and shape design
- JavaScript (ES6) – Application logic and DOM manipulation
- Object-Oriented Programming (OOP) principles

## How to Install / Run
1. Clone the Repository
git clone https://github.com/ValidCoder3000/Shape-factory.git

3. Open the Project Folder
cd shape-factory

5. Run the Application

    Simply open the index.html file in your browser.
    
    You can also use a local development server such as:
    
    npx live-server
    
    or
    
    python -m http.server
